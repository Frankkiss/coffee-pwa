# Coffee PWA Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize the repository foundation for an Android-first coffee PWA using GitHub Pages for frontend deployment and Supabase/DeepSeek as prepared external services.

**Architecture:** The repository root stores project docs, agent instructions, and GitHub workflow files. The Vite React TypeScript app lives in `app/`, builds to `app/dist`, and is deployed to GitHub Pages by GitHub Actions. Supabase and DeepSeek are prepared as service integrations, while business tables and AI functions are covered by separate follow-up plans.

**Tech Stack:** Git, GitHub, GitHub Pages, GitHub Actions, Node.js LTS, Vite, React, TypeScript, Supabase, DeepSeek API.

---

## Scope

This plan only covers the first project foundation stage:

- Repository guidance.
- Local tool checks.
- Vite React TypeScript app initialization.
- GitHub Pages deployment workflow.
- Environment variable examples.
- First build verification.

It does not implement bean storage, brew logs, Supabase database tables, authentication, AI recommendations, source import, or backup logic. Those require separate follow-up implementation plans.

### Task 5: Add GitHub Pages Workflow

**Files:**
- Create: `.github/workflows/deploy-pages.yml`

- [ ] **Step 1: Create workflow file**

Create `.github/workflows/deploy-pages.yml` with:

```yaml
name: Deploy GitHub Pages

on:
  push:
    branches:
      - master
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
          cache-dependency-path: app/package-lock.json

      - name: Install dependencies
        run: npm ci
        working-directory: app

      - name: Build
        run: npm run build
        working-directory: app

      - name: Setup Pages
        uses: actions/configure-pages@v5

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: app/dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 2: Commit workflow**

Run:

```powershell

git commit -m "Add GitHub Pages deployment workflow"
```

Expected output includes:

