# 冲煮模板文本与冷萃模板优化计划

## 目标

- 将冲煮模板里的常见器具名称调整为更自然的中文表达。
- 保留 `V60`、`Origami`、`Orea`、`SOLO Dripper` 等确实以英文或型号称呼为主的名称。
- 补充冷萃壶模板，让模板库覆盖用户主要使用的手冲咖啡和冷萃咖啡。

## 实施范围

1. 更新模板分类，加入 `cold-brew`。
2. 调整模板数据中的器具名称：
   - `Clever Dripper` 改为 `聪明杯`。
   - `Hario Switch` 改为 `Switch 浸泡滤杯`。
   - `Kalita Wave` 改为 `Kalita Wave 平底滤杯`。
3. 新增冷萃壶模板：
   - 经典浸泡。
   - 清爽低苦。
   - 浓缩基底。
4. 优化长时间模板的时间展示，冷萃时间用“小时”表达。
5. 增加测试覆盖中文器具名和冷萃壶模板。

## 非目标

- 不引入新的冷萃设备生态。
- 不改变 DeepSeek 推荐的服务端调用链路。
- 不做整站视觉美化。
