# 豆子详情页 v1 设计

日期：2026-06-15

## 目标

为数字豆仓增加一个手机友好的豆子详情视图，让用户从列表进入单支豆子的完整资料，并能看到这支豆子的历史冲煮摘要。

## 页面形态

第一版不引入独立路由，不做 `/beans/:id`。豆仓列表中点击“详情”后，在豆仓区域内切换到详情视图。详情页提供“返回豆仓”按钮。

这样做的原因：

- 当前应用是 GitHub Pages 上的单页纵向 PWA。
- 不增加路由复杂度，避免刷新路径 404。
- 能复用现有豆仓和冲煮记录数据。

## 展示内容

详情页分为四块：

1. 基础信息
   - 名称、烘焙商、豆子类型、产地、处理法、品种、庄园或处理站、海拔、烘焙度、烘焙日期。

2. 拼配信息
   - 仅拼配豆显示。
   - 展示拼配说明和结构化组成。
   - 比例未知时不显示主次判断，也不暗示主体豆。

3. 风味与库存
   - 风味标签、风味描述、净含量、剩余量、购买日期、价格、来源链接、备注。

4. 冲煮摘要
   - 这支豆子的冲煮次数。
   - 最近三条冲煮记录。
   - 最高评分记录。
   - 已钉选候选方案数量。

## 操作

- 返回豆仓。
- 编辑豆子：复用现有编辑表单。
- 记录冲煮：详情页先显示提示和锚点，引导用户到冲煮记录区；后续版本再做自动预选。

## 数据策略

- `BeanDashboard` 持有 `selectedBeanId`。
- `BrewLogPanel` 继续负责冲煮记录列表和表单。
- 为详情页新增只读 `BeanDetailPanel` 和 `beanDetailModel`。
- `BeanDashboard` 额外加载一份冲煮记录只读数据给详情页使用。若读取失败，详情页仍显示豆子基础信息，并提示冲煮摘要暂不可用。

## 非目标

- 不做独立路由。
- 不做详情页内复杂编辑器。
- 不做图表统计。
- 不直接在详情页创建冲煮记录。
